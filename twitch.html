怎麼辦？

3 個步驟就能開始

設定只要做一次，之後打開這個網頁就會自動連線。資料存在這台電腦的瀏覽器裡。

第一次用？先看 一頁快速上手。看不懂哪一步？📖 打開圖文說明書（每一步都有截圖）

1

連接 Twitch ✓ 完成 看圖解

用你的實況主帳號登入，授權這個網頁「看見忠誠點兌換」。不會發訊息、不會動你的頻道。

已連接：

進階：自訂 Twitch Client ID

這個網站已經內建，一般不用填。只有自己架站、或想改用自己註冊的 Twitch 應用程式時才需要：

  1. 到 dev.twitch.tv/console 登入（帳號需開啟雙重驗證），按「註冊您的應用程式」。
  2. 名稱：自己取（實況主授權時會看到這個名稱，全 Twitch 不能重複）。
  3. OAuth 重新導向網址：（要一字不差）。
  4. 類別：Broadcaster Suite；用戶端類型：公開。按「建立」。
  5. 回主控台對它按「管理」，複製「用戶端 ID」貼到下面。「用戶端密碼」用不到，不要產生也不要給別人。
2

建立觸發轉盤的忠誠點品項 ✓ 完成 看圖解

觀眾兌換這個品項時，就會自動轉一次轉盤。建議直接在這裡建立：網頁關著時的兌換之後也能補抓，撤銷時也能退還忠誠點。

你頻道的品項（勾選的才會觸發轉盤）

先完成步驟 1。

在 Twitch 後台改了品項（改名、停用）後，按 。標示「手動建立」的品項也能用，但網頁關著時的兌換收不到、也不能退點。

3

連接 Google 試算表 ✓ 完成 看圖解

讓轉盤結果自動記到你的試算表。照下面做一次就好（大約 3 分鐘）：

  1. 在 Google 雲端硬碟打開你的轉盤紀錄試算表，上方選單按 擴充功能 → Apps Script。
  2. 把編輯區裡原本的字全部刪掉，按這個按鈕複製程式碼後貼上，再按上方的 💾 儲存。
    （程式碼裡含有只屬於你的暗號）
  3. 按右上角藍色的 部署 → 新增部署作業，左邊齒輪選 網頁應用程式；「執行身分」選我、「誰可以存取」選所有人，按 部署。
  4. Google 會要求授權：按 授權存取 → 選你的帳號。如果出現「Google 尚未驗證這個應用程式」，按左下的 進階 → 前往…（不安全） → 允許。
    為什麼會說「不安全」？

    因為這段程式是你自己剛建立的，沒有送給 Google 審核過，所以 Google 一律這樣提醒。程式只會讀寫你這份試算表，而且只接受帶有你專屬暗號的請求。

  5. 部署完成後，複製「網頁應用程式」底下那串網址（https://script.google.com/… 結尾是 /exec），貼到這裡：
之後改了程式碼要重新部署嗎？

一般不需要再碰。若你按了「換一組暗號」或這個網頁更新了程式碼，請重新複製貼上，然後用 部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署，網址會保持不變。

6

放進 OBS，開台就不用另外開這個網頁 （建議） ✓ 完成 看圖解

你現在就是在 OBS 裡使用：只要 OBS 開著，就會自動接收兌換、轉盤、記到試算表，不用另外開瀏覽器。

把這個網頁放進 OBS 變成一個面板。之後只要開 OBS 就會自動運作，不用再記得開瀏覽器；瀏覽器縮小時可能會變慢的問題也不會發生。

  1. （會把上面設定好的內容一起帶過去，試算表不用重新設定）
  2. OBS 上方選單按 停駐視窗（Docks）→ 自訂瀏覽器停駐視窗…（Custom Browser Docks）。
  3. 「停駐視窗名稱」填 忠誠點轉盤，「URL」按 Ctrl+V 貼上，按 套用，再按 關閉。
  4. OBS 裡會多一個「忠誠點轉盤」面板，可以拖到你喜歡的位置。在面板裡按一次 連接 Twitch 登入，就完成了。
  5. 回到這裡，在「貼到 OBS 了嗎？」按 搬好了。這個分頁就會停止接收兌換（避免兩邊同時轉），可以關掉了。
