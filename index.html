圖片名稱權重機率數量剩餘顏色

機率 ＝ 該獎項權重 ÷ 所有「還有庫存」獎項的權重總和。抽完的獎項會自動退出抽獎池，其餘獎項的機率會動態重新分配。
數量勾選「無限」代表不限量；「剩餘」可手動修改。抽獎前會自動儲存未存的變更。設定存在這個瀏覽器裡，可用「匯出 / 匯入設定」搬到別台電腦。

畫面

「最小扇區寬度」只影響轉盤畫面，讓 1% 的大獎也看得到，抽獎機率不受影響；設 0 則完全依機率比例。

音效

此開關同時套用到控制台與 OBS 覆蓋層；覆蓋層也可用網址參數 sound=0 單獨關閉。

OBS 同步

OBS 設定步驟

  1. 把上面「跨瀏覽器同步」打勾並儲存
  2. OBS → 來源 → ＋ → 瀏覽器，網址填：
    預覽覆蓋層 ↗
  3. 寬 / 高建議 1280 × 720 以上，背景已是透明
  4. 在這個控制台按抽獎，OBS 畫面會同步轉動並顯示結果
  5. 按 確認覆蓋層有收到訊號（覆蓋層右下角有連線狀態小圓點，可用 status=0 隱藏）

覆蓋層網址參數：size 轉盤像素、mode=spin 只在抽獎時顯示轉盤、hide 結果顯示秒數、sound=0 關閉音效。
不想用中繼伺服器？OBS「檢視 → 面板 → 自訂瀏覽器面板」把控制台網址加成面板，再把覆蓋層加為瀏覽器來源，同一個 OBS 內不需要同步伺服器（但 Excel 需改用「下載」）。

Excel 檔案

綁定後每次抽獎都會自動把完整紀錄寫進該檔案（工作表「抽獎紀錄」，其他工作表保留）。重新整理網頁後第一次抽獎時，瀏覽器會再問一次是否允許寫入。
