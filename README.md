# 🎡 Lucky Wheel — 直播用網頁幸運轉盤（純靜態，免安裝）

動態機率 × 獎項庫存 × 連抽 × OBS 透明覆蓋層 × 直接寫入 Excel。
純前端網頁，打開網址就能用；設定與紀錄存在你的瀏覽器裡（IndexedDB，重新整理不會消失）。

**👉 線上使用：<https://yy2401.github.io/lucky-wheel/>**

## 功能

- **動態機率**：每個獎項設定「權重」，機率 = 權重 ÷ 所有還有庫存獎項的權重總和。抽完的獎項自動退出抽獎池，其餘獎項機率即時重新分配（上方有機率長條即時顯示）。
- **獎項數量**：限量（抽完為止）或無限；剩餘數量可手動調整、一鍵重置庫存。
- **建議機率**：不知道權重怎麼設？按「建議機率」輸入預計總抽數 N，數量 q 的獎項機率 = q ÷ N（平均在第 N 抽左右剛好送完，大獎數量少、機率自然低），無限量獎項分掉剩餘機率。預覽表可比對目前 / 建議機率與「平均每幾抽出一次」，套用後再儲存。
- **保底機制**：獎項可勾選「保底」組成保底獎池。累積保底（連續 N 抽沒中，下一抽必中）與連抽保底（每 K 抽至少 1 個）可各自開關；累積計數可依抽獎者分開或全體共用，由紀錄反推，撤銷後自動修正。保底抽到的獎項在結果卡、紀錄與 Excel 都有標記。
- **圖片 / GIF**：每個獎項可上傳圖片（自動縮圖存在瀏覽器）或填圖片網址，顯示在轉盤扇區與結果卡。GIF 動圖（2 MB 內）原檔保留，結果卡與獎項一覽直接播放；轉盤扇區用 `ImageDecoder` 逐格解碼跟著動（Chrome / Edge / OBS），不支援的瀏覽器顯示第一格。
- **互動動畫**：Canvas 轉盤、LED 跑燈、指針彈跳、滴答音效、中獎音效、彩帶。指針落點經 10,000 次自動測試驗證，永遠停在指定獎項扇區的中段。
- **抽獎前倒數**：按下抽獎先倒數 3、2、1（秒數可調、可關），控制台與 OBS 畫面同步；OBS 畫面轉動中會顯示「誰在抽、幾連抽、保底倒數」橫幅。
- **連抽**：單抽 / 三連抽 / 五連抽 / 十連抽 / 自訂連抽（最多 100）。連抽時轉盤轉一次，結果以翻牌逐張揭曉（也可設定成每一抽都轉一次）；可中途「跳過動畫」。空白鍵 = 單抽。
- **OBS 覆蓋層**：透明背景頁面，與控制台即時同步；在控制台按抽獎，OBS 畫面同步轉動並顯示結果卡。
- **Excel**：綁定一個 `.xlsx` 檔（可放桌面或任何位置），每次抽獎自動寫入（工作表「抽獎紀錄」，其他工作表保留）；也可隨時下載。
- **黑底 / 白底主題**：復古遊樂園票券風格，頂欄一鍵切換，OBS 覆蓋層跟著套用（也可用 `theme=light` 參數指定）。
- **備份與還原**：「紀錄 / Excel → 備份全部」把設定、所有抽獎紀錄與偏好存成一個 `.lwbackup` 檔，可整份還原；紀錄累積多而沒備份會提醒。另有只含設定的「匯出 / 匯入設定」。

## 使用方式

1. 打開網頁 → 「獎項設定」：編輯名稱、權重、數量、顏色、圖片 → 儲存設定。
2. 「設定 / OBS」：轉動時間、圈數、扇區顯示方式、音效、OBS 同步。
3. 輸入抽獎者名稱（選填，會寫進 Excel），按「單抽」或連抽按鈕。
4. 「紀錄 / Excel」：綁定 Excel 檔案、下載、關鍵字搜尋紀錄、各獎項統計、撤銷任一批抽獎（庫存加回、紀錄與 Excel 一併移除）、**補抽**某一抽（原筆標作廢並加回庫存、同批次同位置重抽一次，Excel 的「狀態／備註」欄看得出來龍去脈）。結果視窗的卡片滑過也有「補抽」。
5. 抽獎者欄位會列出用過的名字供選擇；同一個瀏覽器只允許一個控制台分頁操作，第二個會被鎖住（可接手）。
6. 手機也能開：定位為遙控器——在電腦設定好獎項，手機按抽獎、看一覽，OBS 在電腦上顯示（同步跨裝置）。手機上預設跳過動畫、不畫 3D 背景。

## OBS 設定

**方法一（推薦）：控制台開在 Chrome，OBS 透過中繼同步**

1. 「設定 / OBS」→ 勾選「跨瀏覽器同步」→ 儲存。
2. 複製「OBS 覆蓋層網址」（含頻道代碼）。
3. OBS → 來源 → ＋ → **瀏覽器**，貼上網址，寬 / 高 1280 × 720 以上。背景已透明。
4. 在 Chrome 控制台抽獎，OBS 同步顯示。

同步透過公開 MQTT 中繼（預設 EMQX 公開測試伺服器），只傳抽獎結果與獎項設定。每則訊息都用一組只出現在 OBS 網址裡的金鑰做 HMAC 簽章，覆蓋層驗簽不過就丟掉，所以即使有人監聽公開伺服器也無法假造結果；「換一組」配對代碼會連金鑰一起換，之後要重新複製網址。也可以改填自己的 MQTT WebSocket 伺服器。

**方法二：全部放在 OBS 裡，不用中繼**

OBS → 檢視 → 面板 → 自訂瀏覽器面板，把控制台網址加成面板；再把覆蓋層網址加為瀏覽器來源。同一個 OBS 內兩者共用瀏覽器儲存，不需要同步伺服器。（此方式 Excel 請改用「下載」）

**覆蓋層網址參數**

| 參數 | 說明 | 範例 |
| --- | --- | --- |
| `room` | 頻道代碼（必填，控制台會自動帶入） | `&room=ABC123` |
| `key` | 簽章金鑰（必填，控制台會自動帶入；沒有或錯誤時收不到任何訊息） | `&key=…` |
| `size` | 轉盤像素大小（預設 520） | `&size=600` |
| `mode=spin` | 平常隱藏轉盤，只在抽獎時淡入 | `&mode=spin` |
| `hide` | 結果卡顯示秒數（預設用控制台設定） | `&hide=10` |
| `sound=0` | 關閉覆蓋層音效 | `&sound=0` |
| `bg=0` | 關閉覆蓋層的 3D 粒子背景（只留轉盤） | `&bg=0` |
| `status=0` | 隱藏右下角的同步狀態小圓點 | `&status=0` |
| `theme` | 強制覆蓋層主題 `dark` / `light`（預設跟控制台） | `&theme=light` |
| `list=1` | 顯示獎項一覽；`lp=0` 不顯示機率、`ls=0` 不顯示剩餘、`lpos=tr` 右上角、`lpos=c` 正中間放大 | `&list=1&lpos=c` |

## Excel

- 使用瀏覽器的 File System Access API（Chrome / Edge），在「紀錄 / Excel」按「建立新的 Excel」或「選擇既有 Excel」綁定檔案；之後每次抽獎自動把完整紀錄寫進工作表「抽獎紀錄」。
- 重新整理網頁後，第一次抽獎時瀏覽器會再問一次是否允許寫入該檔案。
- 欄位：時間、批次ID、抽獎類型、第幾抽、抽獎者/備註、獎項、獎項ID、剩餘數量、當時機率(%)、保底、狀態（正常／作廢）、備註（補抽說明）。
- Firefox / Safari 不支援直接寫入，可用「下載 Excel」。
- 若 Excel 檔正被 Excel 程式開啟（Windows 會鎖檔）導致寫入失敗，紀錄仍在瀏覽器裡，關閉檔案後按「立即寫入」即可。

## 自行架設

純靜態檔案，任何靜態空間都能放（GitHub Pages、Netlify、Cloudflare Pages…），或直接用本機靜態伺服器：

```bash
python3 -m http.server 3000
```

> 注意：Excel 直接寫入與 BroadcastChannel 需要 https 或 localhost。

## 測試

```bash
npm install        # 只需一次（裝 puppeteer-core，用本機 Chrome 跑端對端測試）
npm run lint       # ESLint
npm test           # 單元測試：設定正規化、機率、保底、撤銷、轉盤落點（約 1.5 秒）
npm run test:e2e   # 端對端：真實 Chrome 跑抽獎、撤銷、搜尋、設定、主題、資料搬移、OBS 同步（約 1 分鐘）
```

每次推上 GitHub 都會自動跑兩套測試（見 Actions 頁籤）。

## 專案結構

```
index.html   控制台 + OBS 覆蓋層（?overlay=1）
app.js       進入點：載入儲存層後依網址啟動控制台或覆蓋層
core.js      純邏輯：設定正規化、機率、建議機率、抽獎、保底、撤銷（瀏覽器與 Node 共用）
control.js   控制台：獎項表格、設定頁、紀錄 / 統計、抽獎流程
overlay.js   OBS 覆蓋層：聽同步頻道、播放轉盤與結果卡
ui.js        共用介面：DOM 工具、提示、頁內對話框、結果卡、主題
store.js     儲存層（IndexedDB，含舊版 localStorage 搬移）
sync.js      同步頻道（BroadcastChannel + MQTT）
excel.js     Excel 綁定與寫入（File System Access API + SheetJS）
wheel.js     轉盤引擎（繪製、動畫、音效、彩帶）
bg.js        Three.js 3D 動態背景（僅控制台，覆蓋層維持透明）
style.css
test/unit/   單元測試（node --test）
test/e2e/    端對端測試（puppeteer-core）
```

外部套件（CDN）：[SheetJS](https://sheetjs.com/) 產生 Excel、[MQTT.js](https://github.com/mqttjs/MQTT.js) 跨瀏覽器同步、[Three.js](https://threejs.org/) 3D 動態背景、[anime.js](https://animejs.com/) 介面動畫。
