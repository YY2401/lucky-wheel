# 🎡 Lucky Wheel — 直播用網頁幸運轉盤（純靜態，免安裝）

動態機率 × 獎項庫存 × 連抽 × OBS 透明覆蓋層 × 直接寫入 Excel。
純前端網頁，放在 GitHub Pages 上，打開網址就能用；設定與紀錄存在你的瀏覽器裡。

## 功能

- **動態機率**：每個獎項設定「權重」，機率 = 權重 ÷ 所有還有庫存獎項的權重總和。抽完的獎項自動退出抽獎池，其餘獎項機率即時重新分配（上方有機率長條即時顯示）。
- **獎項數量**：限量（抽完為止）或無限；剩餘數量可手動調整、一鍵重置庫存。
- **圖片**：每個獎項可上傳圖片（自動縮圖存在瀏覽器）或填圖片網址，顯示在轉盤扇區與結果卡。
- **互動動畫**：Canvas 轉盤、LED 跑燈、指針彈跳、滴答音效、中獎音效、彩帶。指針落點經 10,000 次自動測試驗證，永遠停在指定獎項扇區的中段。
- **連抽**：單抽 / 三連抽 / 五連抽 / 十連抽 / 自訂連抽（最多 100）。可選「快速模式」只轉一次直接顯示全部結果，也可中途「跳過動畫」。空白鍵 = 單抽。
- **OBS 覆蓋層**：透明背景頁面，與控制台即時同步；在控制台按抽獎，OBS 畫面同步轉動並顯示結果卡。
- **Excel**：綁定一個 `.xlsx` 檔（可放桌面或任何位置），每次抽獎自動寫入（工作表「抽獎紀錄」，其他工作表保留）；也可隨時下載。
- **設定匯出 / 匯入**：JSON 檔，方便換電腦或備份。

## 使用方式

1. 打開網頁 → 「獎項設定」：編輯名稱、權重、數量、顏色、圖片 → 儲存設定。
2. 「設定 / OBS」：轉動時間、圈數、扇區顯示方式、音效、OBS 同步。
3. 輸入抽獎者名稱（選填，會寫進 Excel），按「單抽」或連抽按鈕。
4. 「紀錄 / Excel」：綁定 Excel 檔案、下載、查看與清除紀錄。

## OBS 設定

**方法一（推薦）：控制台開在 Chrome，OBS 透過中繼同步**

1. 「設定 / OBS」→ 勾選「跨瀏覽器同步」→ 儲存。
2. 複製「OBS 覆蓋層網址」（含頻道代碼）。
3. OBS → 來源 → ＋ → **瀏覽器**，貼上網址，寬 / 高 1280 × 720 以上。背景已透明。
4. 在 Chrome 控制台抽獎，OBS 同步顯示。

同步透過公開 MQTT 中繼（預設 EMQX 公開測試伺服器），只傳抽獎結果與獎項設定；頻道代碼是隨機的，可在設定裡重新產生。也可以改填自己的 MQTT WebSocket 伺服器。

**方法二：全部放在 OBS 裡，不用中繼**

OBS → 檢視 → 面板 → 自訂瀏覽器面板，把控制台網址加成面板；再把覆蓋層網址加為瀏覽器來源。同一個 OBS 內兩者共用瀏覽器儲存，不需要同步伺服器。（此方式 Excel 請改用「下載」）

**覆蓋層網址參數**

| 參數 | 說明 | 範例 |
| --- | --- | --- |
| `room` | 頻道代碼（必填，控制台會自動帶入） | `&room=ABC123` |
| `size` | 轉盤像素大小（預設 520） | `&size=600` |
| `mode=spin` | 平常隱藏轉盤，只在抽獎時淡入 | `&mode=spin` |
| `hide` | 結果卡顯示秒數（預設用控制台設定） | `&hide=10` |
| `sound=0` | 關閉覆蓋層音效 | `&sound=0` |

## Excel

- 使用瀏覽器的 File System Access API（Chrome / Edge），在「紀錄 / Excel」按「建立新的 Excel」或「選擇既有 Excel」綁定檔案；之後每次抽獎自動把完整紀錄寫進工作表「抽獎紀錄」。
- 重新整理網頁後，第一次抽獎時瀏覽器會再問一次是否允許寫入該檔案。
- 欄位：時間、批次ID、抽獎類型、第幾抽、抽獎者/備註、獎項、獎項ID、剩餘數量、當時機率(%)。
- Firefox / Safari 不支援直接寫入，可用「下載 Excel」。
- 若 Excel 檔正被 Excel 程式開啟（Windows 會鎖檔）導致寫入失敗，紀錄仍在瀏覽器裡，關閉檔案後按「立即寫入」即可。

## 自行架設

純靜態檔案，任何靜態空間都能放（GitHub Pages、Netlify、Cloudflare Pages…），或直接用本機靜態伺服器：

```bash
python3 -m http.server 3000
```

> 注意：Excel 直接寫入與 BroadcastChannel 需要 https 或 localhost。

## 專案結構

```
index.html   控制台 + OBS 覆蓋層（?overlay=1）
app.js       抽獎邏輯、設定 / 紀錄儲存、同步頻道、Excel 寫入
wheel.js     轉盤引擎（繪製、動畫、音效、彩帶）
style.css
```

外部套件（CDN）：[SheetJS](https://sheetjs.com/) 產生 Excel、[MQTT.js](https://github.com/mqttjs/MQTT.js) 跨瀏覽器同步。
